#  Java Swing Akıllı Araç Değerleme Sistemi

Merhaba!  Bu proje, otomobil piyasasındaki verileri analiz ederek kullanıcıların marka, model, yıl, kilometre ve hasar durumu gibi kriterlere göre anlık araç değeri hesaplayabilmesini sağlayan nesne yönelimli bir masaüstü uygulamasıdır.

##  Projenin Hikayesi ve Amacı
Otomotiv sektöründe doğru fiyatlandırma yapabilmek her zaman merak uyandırıcı bir süreç olmuştur. Bu projede hem **Java** dilindeki nesne yönelimli programlama (OOP) yetkinliklerimi pekiştirmek hem de kullanıcı dostu, akıllı bir algoritmayla çalışan masaüstü arayüzü (`Java Swing`) geliştirmek istedim.

##  Öne Çıkan Özellikler
- **Geniş Marka & Model Kataloğu:** Onlarca farklı marka ve modelin geçmişten günümüze veri tabanını barındırır.
- **Akıllı Fiyat Türetme Algoritması:** Doğrudan kaydı bulunmayan yıl veya varyasyonlar için matematiksel ve üssel büyüme modelleri kullanarak en yakın veriden mantıklı fiyat tahmini yapar.
- **Kriter Bazlı Optimizasyon:** Kilometre, değişen parça ve hasar kaydı gibi etkenleri hesaba katarak fiyatı dinamik olarak günceller.
- **Modern Arayüz:** Java Swing bileşenleriyle tasarlanmış, akıcı ve sezgisel bir kullanıcı deneyimi.

##  Kullanılan Teknolojiler
- **Programlama Dili:** Java (OOP)
- **Arayüz Kütüphanesi:** Java Swing (JFrame, JPanel, Layouts)
- **Geliştirme Ortamı:** Eclipse IDE
- **Versiyon Kontrol:** Git & GitHub
